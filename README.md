# 🛡️ Credit Card Fraud Detection using Machine Learning

## 📌 Overview

This project is a Machine Learning-based web application that detects fraudulent credit card transactions using Logistic Regression trained on an imbalanced dataset. The application is built with Streamlit and supports both single transaction prediction and batch prediction using CSV files.

---

## 🚀 Features

- 💳 Single Transaction Prediction
- 📂 Batch Prediction using CSV Upload
- 📊 Fraud Probability Score
- 📈 Prediction Summary Chart
- 📋 Dashboard Metrics
- 🔍 Show Only Fraud Transactions
- 📥 Download Prediction Results
- 🎨 Interactive Streamlit UI

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Imbalanced-learn (SMOTE)
- Joblib

---

## 🤖 Machine Learning Model

- Algorithm: Logistic Regression
- Feature Scaling: StandardScaler
- Imbalanced Data Handling: SMOTE
- Prediction: Fraud / Genuine
